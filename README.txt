SMART CAMPUS FINAL MINI PROJECT
1. Install XAMPP and start Apache + MySQL.
2. Copy this folder to C:\xampp\htdocs\
3. Open phpMyAdmin and import database/smart_campus.sql.
4. Open http://localhost/Smart_Campus_Final_Project/setup.php
5. Delete setup.php after it runs.
6. Open http://localhost/Smart_Campus_Final_Project/
